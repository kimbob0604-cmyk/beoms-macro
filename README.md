# Beom's Macro

매크로 전용 대시보드. 시장 전체의 위치(흐름·타이밍·비중·섹터)만 본다. Beom's Dashboard 와는 별도 사이트이고, 모든 화면은 이 안에서만 구현한다.
계획·지표별 출처 검증: `~/Beom's Dashboard/docs/macro-plan.md`.

구조: Python 수집기 → SQLite(`db/macro.db`) → `public/data/*.json` → 프레임워크 없는 정적 화면.

```bash
python3 run_daily.py            # 수집 8종(시세·변동성·한국 폭·FRED·한국 금리/수급·심리/포지션·IB 재료·파생) → 빌드. 하루 세 번 launchd 가 돌린다
python3 run_daily.py --build    # 빌드만
python3 serve.py                # http://127.0.0.1:8770 (이 컴퓨터에서만)

python3 collect_market.py [--full]    # 지수·변동성·금리·환율·원자재·ETF·해외 종목 (Yahoo Finance). 처음 받는 계열·--full 은 2005년부터, 그 뒤 최근 3개월
python3 collect_vol.py [--days N]     # VIX 기간구조(CBOE) + VKOSPI(KRX Open API, 하루치씩 → --days 로 과거 채우기)
python3 collect_breadth.py [--full]   # 한국 폭 지표(ADR·볼밴·RSI·신고가/신저가·이평선 위 비율) + 업종별 과매도 지도 + 페어용 종목 계열
python3 collect_fred.py [--full]      # 미국 금리·신용 스프레드·유동성·경기 (FRED). 순유동성·CP 스프레드·SOFR−IORB 는 여기서 계산
python3 collect_kr.py [--full]        # 한국 금리(ECOS) · 신용잔고·예탁금·반대매매(금융투자협회) · 중국 신용잔고(이스트머니)
python3 collect_sent.py               # CNN·크립토 공탐지수 · DIX/GEX · CBOE 풋콜 · S&P500 PER(multpl) · CFTC 포지션
python3 collect_trend.py [--seed]     # 추세추종: 지수 종가·거래량, 트렌드 템플릿·와인스타인 단계 비율(한국 전 종목·S&P500), 통과 종목 (--seed: 맥에서 과거 이력 → seed_trend.json.gz)
python3 collect_ib.py [--full]        # 국가 ETF 43개(글로벌 폭) · 나스닥÷NYSE 거래량 · 미국 공매도 잔고(FINRA)
python3 collect_deriv.py [krx|kis|opt] [--full]   # KRX 선물·옵션 일별 · 한국투자증권 대차/공매도/선물 수급 · 미국 옵션 체인. 처음엔 선물 750일·옵션 500일(10분쯤)
python3 build.py                      # 화면용 JSON (build2.py = 비중·수급·공탐지수·AI 크레딧, build3.py = IB 지표판·CTA 모델·파생·평단)
```

## 계산 메모

- 보통주만(코드 끝자리 0), 스팩 제외. RSI 는 거래 없는 날·상장폐지 뒤를 비운다(ewm 이 직전 값을 이어 붙이는 것 방지).
- '상위 5%' 기준은 그날 이전 750거래일로만 계산한다(미래 값 미사용). 신호 사건은 20거래일 안의 반복을 한 번으로 센다.
- 한국 폭 지표는 KRX Open API(다음 날 08시쯤)에서 빠진 날의 전 종목 일봉을 직접 받아 채운다(`kr_px`).
- 국면의 '유동성·크레딧' 축(2단계부터): 하이일드·CCC 스프레드 60일 변화(역), 연준 순유동성 13주 변화, NFCI(역), 달러 60일 변화(역), 실질금리 60일 변화(역)의 백분위 평균.
- 한국판 공탐지수·AI 크레딧 스트레스: 각 항목을 '그날까지의 최근 500일 중 몇 %'로 바꿔 평균(항목 4개 이상 있을 때만).
- ICE BofA 스프레드는 FRED 가 최근 3년치만 준다(2023-11~). 풋콜·PER 는 과거 값이 없어 하루씩 쌓는다.
- '늦음' 기준은 주기별: 매일 5일 · 주간 12일 · 격주 35일 · 월간 100일 · 분기 250일.
- 위험선호 지수(RAI식): 쌍마다 3개월 로그 상대수익률 → 최근 3년(756일) 평균·표준편차로 z → 평균(쌍 6개 이상일 때). '하위 5% 선'은 그날까지의 값으로만 정한다.
- CTA 추정 포지션: sign(P ÷ P[n일 전] − 1) 의 평균(n = 20·60·125·250) × min(1, 15% ÷ 60일 변동성). 신호가 바뀌는 가격 = 내일 신호의 기준(오늘 기준 n−1일 전 종가). 표의 매수·매도 표시는 오늘 신호라 기준가와 1거래일 어긋날 수 있다. 설명력은 자산마다 위험을 같게, 자산군 4개를 같은 비중으로 둔 포트폴리오의 주간 수익률과 CTA ETF 를 비교한다.
- 누적 VWAP: 기준일부터 Σ거래대금 ÷ Σ(거래대금 ÷ 수정 VWAP). 수정은 등락률을 거꾸로 곱해 마지막 종가에 맞춘다(분할·권리락 반영). 주체별 평단은 순매수한 날의 (순매수 수량 × 그날 VWAP) 평균 — 추정.
- 페어 z-점수: ln(A÷B) 의 250일 평균·표준편차. 과거 근거는 |z|≥2 인 날 반대로 서서 60거래일 들고 있었을 때(20일 안의 반복은 한 번).
- KRX 선물·옵션은 날짜별로 받고 `drv_done` 에 받은 날을 적어 이어받는다(값과 표시를 같이 저장). 통화 스왑 대용 = 달러선물 (차근월 ÷ 근월 − 1) 연율 − (CD 91일 − SOFR).
